# 直接以 BLE 連線戒指並自行解析協定

PulseRing 的原廠 FixFate app 不會把資料寫進 Health Connect，也沒有公開 SDK 或 API。要自己掌控資料並自建資料庫，唯一的路是直接以 BLE 連線，並逆向其協定。

這代表戒指同一時間只能由一個 app 使用：開始使用本 app 後，要先解除與 FixFate 的綁定，原廠的 AI 助理與家人共享就用不到。

## 考慮過的替代方案

- Health Connect：原廠沒有寫入，不可行。
- 原廠雲端 API：沒有公開文件，且資料不在自己手上。

## 後果

- 協定隨原廠韌體更新可能改變，所以才保留 Raw Frame（見 0001）。
- 協定知識記錄在 `docs/ring-protocol.md`，並以側錄檔做回放測試。
